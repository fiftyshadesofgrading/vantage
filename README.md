# Vantage · Cape Ann

Walk Gloucester and Rockport to the spots where Fitz Henry Lane, Winslow Homer,
Childe Hassam, Edward Hopper and the Detroit Publishing photographers set up,
then line their picture up with the real view.

`/vantage/` on the NAS Apache site (port 8888). It's a static web app (HTML, CSS and
ES modules) with no build step and no backend.

## What's in it

| Path | What |
|---|---|
| `index.html`, `css/`, `js/` | The app: Leaflet map, list/detail sheet, ghost view, photo match, high-res viewer |
| `lib/leaflet/` | Leaflet 1.9.4 (vendored, BSD-2) |
| `data/artworks.json` | The catalogue: 34 public-domain works, each with vantage point, bearing, angle of view, confidence and sources. Generated by `tools/build_catalog.py`. |
| `data/local.json` | Written by `fetch_art.py`; tells the app which local high-res copies exist |
| `data/calibrations.json` | Shared field calibrations (export from the app, drop in here) |
| `tools/build_catalog.py` | Source of truth for the catalogue. Edit the list, re-run, done. |
| `tools/fetch_art.py` | Highest-resolution downloader (see below) |
| `art/` | Created by `fetch_art.py`: `originals/` (untouched, git-ignored), `full/`, `web/`, `thumbs/`, `inbox/` |

## Using it

* **Map**: each pin is an easel or camera position. The shaded cone is the view: its
  bearing and roughly how wide the picture spans. A number on a pin means several works
  were made from the same spot (e.g. the Universalist church: Hassam ×2 + Hopper).
  Pins with dashed rings are *general area* only.
* **Ghost view**: the camera, with the picture floating on top. Drag, pinch and rotate it.
  *Fade* blends; *Swipe* gives a then/now curtain. The guide panel shows distance to
  the spot and "turn N° left/right". With *Slide with compass* on, the picture moves
  as you turn, a rough AR effect. *Hold* freezes the frame so you can align slowly.
  The round button saves a then-and-now JPEG.
* **Photo match**: take or choose a photo and align on it. Works on plain HTTP.
* **Desk testing**: right-click (long-press) the map → *Pretend I'm standing here*, or
  add `?sim=42.6092,-70.6662` to the URL. In the console,
  `vantage.S.fakeHeading(176)` feeds a compass heading.

### Camera, GPS and compass need HTTPS

Browsers block `getUserMedia`, geolocation and device orientation on plain-HTTP pages,
so on `http://192.168.50.88:8888/vantage/` you get the map and photo match only.
To use the live mode on your phone in Gloucester, serve the same folder over HTTPS.
The easiest route is **Tailscale Serve** on the NAS, which keeps it private to your tailnet:

```sh
# on the NAS (ssh), once
sudo /var/packages/Tailscale/target/bin/tailscale serve --bg 8888
# then on the phone, with Tailscale connected:
#   https://<nas-machine-name>.<your-tailnet>.ts.net/vantage/
```

This needs MagicDNS and **HTTPS Certificates** enabled in the Tailscale admin console
(DNS page). `tailscale serve status` shows the URL, and `tailscale serve --https=443 off`
undoes it. If your Synology package version won't do `serve`, a DSM reverse-proxy rule with
a Let's Encrypt certificate works too. Since everything here is public domain and static,
any HTTPS static host works as well (GitHub Pages, say).

Calibrations live in each browser's local storage, which is per address (the LAN URL
and the ts.net URL are separate). Use **Export** and `data/calibrations.json` to move them.

## Getting the highest-resolution images

The app starts out showing Wikimedia Commons copies (1920 px for overlays, up to 3840 px
in the zoom viewer). To keep full-quality originals on the NAS and serve them locally:

```sh
pip install pillow                     # optional but recommended (builds the JPEGs)
cd "Z:\02 Software\20 Webhosting\vantage"    # or /mnt/nas/02 Software/... on the Ubuntu box
python tools/fetch_art.py --all --dry-run    # see where each image will come from
python tools/fetch_art.py --all              # download everything (~0.6 GB, mostly one LOC TIFF)
```

For each work it tries the **museum's own original first** (The Met's open-access master,
Cleveland's print file, the Library of Congress TIFF), then Wikimedia Commons, and keeps
whichever has more pixels. Every original gets a `.json` sidecar with the source URL,
licence, pixel size and SHA-256. It writes `data/local.json`, and the app switches to
the local files automatically (falling back to Commons if a file is missing).

**Paste-a-link mode** for anything new you find:

```sh
python tools/fetch_art.py "https://commons.wikimedia.org/wiki/File:Some_painting.jpg"
python tools/fetch_art.py https://www.metmuseum.org/art/collection/search/11396
python tools/fetch_art.py https://www.artic.edu/artworks/16800
python tools/fetch_art.py https://www.loc.gov/item/2007626395/
python tools/fetch_art.py https://some.iiif.server/iiif/abc123/info.json
```

These go to `art/inbox/`. It understands Commons (page, upload or thumbnail URLs), The Met,
Art Institute of Chicago, Cleveland Museum of Art, Library of Congress *item* links, NGA
object pages (via their IIIF image), any IIIF `info.json`, and direct image URLs. It
warns when a museum says a work is **not** public domain. Use `--max-mb` to cap single
files (default 400), and set `VANTAGE_CONTACT=you@example.com` to add contact info to the
User-Agent (Wikimedia asks scripted clients to).

**Where else to look for high-res public-domain art:** Wikimedia Commons (search the
artist's category; museum uploads are tagged *MET*, *NGA*, *Google Art Project*), The Met
Open Access, NGA Open Access, Art Institute of Chicago, Cleveland Open Access, Yale Center
for British Art, LOC Prints & Photographs (Detroit Publishing glass negatives are huge
TIFFs) and NYPL Digital Collections (photochroms).

## Harvesting everything (Cape Ann + Portland area)

`tools/harvest.py` sweeps the open collections in one go, downloads the best public-domain
originals, and builds a gallery you can triage later:

```sh
python tools/harvest.py                    # discover → download → gallery; re-run to resume
python tools/harvest.py discover           # metadata only (fast), writes harvest/manifest.jsonl
python tools/harvest.py --region portland --sources loc --budget-gb 60
```

It searches Wikimedia Commons, The Met (open-access CSV), National Gallery of Art (open
data), Cleveland (CC0, full-res TIFFs up to ~13,000 px), Art Institute of Chicago and the
Library of Congress (Detroit Publishing and other pre-1931 photos, HABS, bird's-eye views,
Sanborn maps). Artists and place names live at the top of the script (Lane, Mellen, Homer,
Hassam, Twachtman, Metcalf, Prendergast, Sloan, Beaux, Buhler… Codman, Kimball, Harrison
Bird Brown, Hudson, Hathaway, Griffin…). Edit those lists to widen or narrow the sweep.

Downloads are in priority order — artworks, then photographs, then HABS, then Sanborn sheets —
and stop at `--budget-gb` (default 250). Files go to `art/library/<region>/<source>/` with
a JSON provenance sidecar each. Open `harvest/gallery.html` (it's served at
`/vantage/harvest/gallery.html`) to filter, tick the ones worth pinning, and **Export picks**.

## How sure are the pins?

* **Documented (13)**: from a published viewpoint map or catalogue note, almost all from
  Erik Ronnberg's viewpoint charts in the Cape Ann Museum's *Fitz Henry Lane Online*
  catalogue raisonné. These are still my reading of hand-drawn charts onto modern
  coordinates, so expect tens of metres of error. The *bearing* is the most reliable part.
* **Inferred (12)**: worked out from the title and geography.
* **General (9)**: right neighbourhood, exact spot unknown.

The fix is **field calibration**: at the spot, line the picture up, open ◎, tap
*Save this alignment*. It records your GPS position, the true bearing of the picture's
centre and its measured angular width (from how big it ends up on screen, given the
camera FOV setting). Export and drop into `data/calibrations.json`, or fold the numbers
into `tools/build_catalog.py`. Compass headings are corrected for Cape Ann's magnetic
declination (−14.4°, editable in `js/store.js`).

Camera FOV defaults to 66° across the long side of the frame (typical phone main camera).
If pictures come up consistently too big or small, adjust it in the calibration drawer.

## Adding works

Add an entry to `CATALOG` in `tools/build_catalog.py` (Commons filename, pixel size in
`SIZES`, vantage lat/lon, heading, fov, confidence, basis, note), run
`python tools/build_catalog.py`, then `python tools/fetch_art.py --id <new-id>`.
Good next candidates: Lane's *View from Rocky Neck* drawings, Homer's 1880 Ten Pound
Island watercolours, Hassam's 1890s Gloucester harbour pictures, Twachtman's 1900–02
harbour views, more Detroit Publishing glass negatives from LOC, and Rockport
(Motif No. 1, Bearskin Neck). Leave out anything still in copyright (most Hopper after
1930, Stuart Davis, etc.), or add it as a pin without an image.
